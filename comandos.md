# Comandos

En el aula trabajar con cmd

## Verificar si node está instalado

https://nodejs.org/en/download

node -v

## Verificar si tenemos NPM

https://www.npmjs.com/

npm -v

## Instalar PNPM

https://pnpm.io/es/

npm i -g pnpm

pnpm -v

pn -v

### Inicializar proyecto

Recordar estar en la carpeta del proyecto

pn init

### Configurar scripts

"dev": "five-server"

### Instalar paquetes

pn add nombre-paquete
